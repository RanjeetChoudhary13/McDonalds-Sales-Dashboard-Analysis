# McDonald's Sales Analysis Dashboard

##  Project Overview
This project analyzes McDonald's sales data using Excel, Power Query, Pivot Tables, and interactive dashboards. The dashboard provides insights into revenue trends, top-selling items, order behavior, and customer purchasing patterns.

---

##  Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers

---

##  Key KPIs
- Total Revenue: ₹61,004
- Total Orders: 5,343
- Average Items per Order: 2.26
- Top Ordered Item: Big Mac

##  Data Cleaning Process
- Removed null values
- Cleaned text columns
- Standardized date formats
- Extracted Month Name and Day Name
- Created Time Bucket column
- Created Day Type column
- Merged menu item dataset with order dataset

---

##  Key Insights
- Burger category generated highest revenue.
- Evening time received maximum orders.
- Weekend sales were higher than weekday sales.
- Big Mac was the most ordered item.
- Revenue peaked during March.
